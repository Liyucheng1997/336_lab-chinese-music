# 金声玉振 · 曾侯乙编钟（Three.js）

以曾侯乙编钟为原型的三维演奏系统：三层钟架、五十五钟、一钟双音，内置《秦王破阵乐》《十面埋伏》《高山流水》。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 输出到 dist/，可直接静态部署
```

## 功能

- **钟体建模**：合瓦形截面（两段圆弧相交）、弧形于口、尖锐铣棱；甬钟带 36 枚螺旋枚、甬、旋、斡，斜挂；钮钟直挂。
- **程序化纹理**：篆带蟠螭纹、舞部云雷纹、鼓部对称蟠龙纹、侧鼓鸾鸟标记、钲部错金铭文「曾侯乙作持用終」；青铜锈色、凹处积垢、腐蚀麻点均由噪声生成。
- **钟架**：朱黑漆绘横梁、青铜套头、三层青铜佩剑武士柱（双手与冠顶承梁）。
- **声音**：非整数倍分音的加法合成（成对分音产生缓慢的拍），木槌击铜的噪声瞬态，一钟双音的串音；殿堂卷积混响、立体声定位、力度相关的音色明暗。
- **视觉反馈**：挥槌动画（下层撞钟棒、中上层丁字槌）、钟体摆动与微振、错金纹饰发光、声波涟漪、金色火星。
- **殿堂氛围**：模糊镜面地面、窗棂天光光柱、浮尘、青铜灯台火焰、建鼓（蟠龙鼓座、羽葆）、Bloom 与暗角后期。
- **演奏**：分段字幕、简谱卷轴、进度跳转、变速、自动运镜。

## 自由演奏

- 点击钟体：钟口正中为 **正鼓音**，偏向两侧为 **侧鼓音**；越靠近鼓部越响。
- 键盘（1 = C）：`Z`–`M` 低音、`A`–`J` 中音、`Q`–`U` 高音，`Shift` 升半音，`空格` 击建鼓。
- 鼠标拖动旋转、滚轮缩放、右键平移；点击「曲 目」标题可收起面板。

## 简谱记法（`songs.js`）

`1–7` 音符，`0` 休止；`'` / `,` 高低八度；`_` 八分、`=` 十六分、`.` 附点；`-` 延长一拍；
`*n` 轮奏 n 次；`!` 重音；`a+b` 和音，`~` 前缀为琶音刮奏；`^n` 倚音；`pp`–`ff` 力度；
鼓轨 `D d x R`（重击 / 中击 / 击框 / 滚奏）；`( … )x2` 反复。

曲谱为编钟改编版：保留各曲的段落结构与气质（五声调式、1 = D），并非原谱逐音移植。
